RF07 · Registro
RF07.1 El sistema deberá permitir registrarse con correo y contraseña.
RF07.2 El sistema deberá validar que el correo sea único.
RF07.3 El sistema deberá rechazar contraseñas de menos de 8 caracteres.
RF07.4 El sistema deberá mostrar un mensaje de confirmación al registrarse correctamente.

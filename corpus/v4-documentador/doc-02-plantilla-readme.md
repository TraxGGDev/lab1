Todo servicio tiene un README.md con estas secciones, en este orden:
1. Nombre y propósito (2 o 3 oraciones: qué hace y para quién).
2. Requisitos (versión de Python, dependencias del sistema).
3. Instalación y ejecución local (comandos exactos).
4. Configuración: tabla de variables de entorno con nombre, descripción, obligatoria (sí/no) y valor por defecto. Nunca valores reales de secretos.
5. Endpoints: tabla con método, ruta, descripción y autenticación.
6. Errores: tabla de códigos y su significado.
7. Pruebas: cómo correrlas.
8. Dueño del servicio y canal de soporte.

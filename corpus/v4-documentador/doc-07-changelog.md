Formato Keep a Changelog: secciones Añadido, Cambiado, Obsoleto, Eliminado, Corregido y Seguridad, bajo una versión con fecha (AAAA-MM-DD).

Versionado semántico: MAYOR para cambios incompatibles, MENOR para funcionalidad compatible, PARCHE para correcciones.

Cada entrada describe el efecto para quien usa el servicio, no el detalle de implementación.
